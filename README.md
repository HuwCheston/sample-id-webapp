# Sample ID: Web Application

This is the web application associated with the paper _"Automatic Identification of Samples in Hip-Hop Music via Multi-Loss Training and an Artificial Dataset"_ by Huw Cheston, Jan Van Balen, and Simon Durand. 

Model training code, checkpoints etc., will be released at a later date.

You can access the web application at http://huwcheston.github.io/sample-id-webapp/index.html and read the paper at https://arxiv.org/abs/2502.06364
